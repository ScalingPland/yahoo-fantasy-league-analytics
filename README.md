# Yahoo Fantasy League Analytics

Personal, noncommercial fantasy football analytics project for analysing historical draft, auction, roster and league data from a single Yahoo Fantasy Football league. Intended for one user. Uses read-only Yahoo Fantasy Sports API data.

## Project goals

This project will:

- Analyse historical auction and snake drafts
- Study manager tendencies and positional spending
- Reconstruct auction budgets and maximum bids
- Support a future live auction assistant
- Remain personal and noncommercial

## Data and credentials

Yahoo Fantasy Sports API access is read-only. API keys, OAuth secrets, client secrets, Yahoo tokens, personal league data and downloaded datasets must never be committed to this repository.
